# Media sources

## AI-generated visuals

The five files in `assets/ai-media/` were generated for this presentation using the user-provided underwater image as a mood reference only. They are atmosphere layers, not substitutes for exact product photography or technical specifications.

The local MP3 files in `assets/audio/` are preview files downloaded from Mixkit's free transition sound-effects library. They are used as short page-change cues; the section beds are generated locally with the Web Audio API so the deck remains self-contained.
